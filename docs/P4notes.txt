>> Replacing the bounded mutex queue with an SPSC ring buffer improved producer-consumer throughput ~3.2x
|__>> Reduced p50 pipeline latency by ~70% under the same unpaced workload.

| Experiment                            |      Baseline |     Optimized | Result               |
| ------------------------------------- | ------------: | ------------: | -------------------- |

| Batch size 1 → 32                     |  8.17 M msg/s | 13.13 M msg/s | **~61% throughput**  |
